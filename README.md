# Responsive Navbar with Hamburger Menu 🍔

## 📌 Project Overview
This project is part of my **Veda Technology Web Development Internship**. It is a responsive navigation bar built using HTML5, CSS3, and JavaScript. The navbar displays horizontally on desktop screens and transforms into a hamburger menu on mobile devices.

## ✨ Features
- 📱 Responsive design for desktop, tablet, and mobile screens
- 🍔 Interactive hamburger menu for mobile devices
- 🎨 Modern and clean user interface
- 🔄 Smooth menu opening and closing transitions
- 🧭 Navigation links for Home, About, Services, Projects, and Contact
- ✅ Animated hamburger icon that transforms into a close icon
- ⌨️ Keyboard support using the Escape key
- ♿ Accessible menu controls

## 🛠️ Technologies Used
- **HTML5** – Structure of the webpage
- **CSS3** – Styling, media queries, and transitions
- **JavaScript** – Interactive menu functionality

## 🚀 How to Run the Project
1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension if needed.
4. Right-click `index.html`.
5. Select **Open with Live Server**.
6. Resize the browser to test the responsive layout.
