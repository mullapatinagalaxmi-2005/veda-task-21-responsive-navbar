
# Responsive Navbar with Hamburger Menu

## Project Overview
This project is a responsive navigation bar created using HTML5, CSS3, and JavaScript. It displays a horizontal navigation menu on desktop screens and a hamburger menu on mobile screens.

## Features
- Responsive desktop and mobile layouts
- Hamburger menu for smaller screens
- Smooth menu opening and closing transitions
- Animated hamburger-to-close icon
- Navigation links to page sections
- Keyboard Escape support
- Accessible menu controls

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
